## 项目

### 抖音图文提取器

面向个人学习与技术研究的抖音内容保存工具，Windows 桌面版（Tkinter）与原生 Android 版共用一套提取思路。

- 批量解析公开分享页，保存图文原图、文案、作者信息和可选 MP4
- 图片按顺序自动合成独立 PDF，并导出到系统相册
- Android 单元测试跑在本地 JVM，CI 自动构建并发布 debug APK

[仓库](https://github.com/adigailmichael19-art/douyin-image-extractor) · [下载 APK](https://github.com/adigailmichael19-art/douyin-image-extractor/releases/tag/android-debug) · [更新记录](https://github.com/adigailmichael19-art/douyin-image-extractor/blob/main/CHANGELOG.md)

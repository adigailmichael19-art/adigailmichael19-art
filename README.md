## 项目

### 抖音图文提取器 · 可用

Windows 桌面版（Tkinter）+ 原生 Android 版的内容保存工具：批量提取公开图文作品的原图与文案、可选 MP4，自动合成 PDF 并导出相册。

`Python` `Tkinter` `requests` `Pillow` `Java` `Android SDK` `Gradle` `GitHub Actions` · MIT

[主仓库](https://github.com/adigailmichael19-art/douyin-image-extractor) · [下载 APK](https://github.com/adigailmichael19-art/douyin-image-extractor/releases/tag/android-debug) · [使用指南](https://github.com/adigailmichael19-art/douyin-extractor-guide)
